# Source and attribution

The Pond Dash code, canvas illustration, SVG cover and favicon were created for this assignment. There are no third-party game engines, runtime packages, remote fonts, sampled audio, external images, or analytics in the export. The browser synthesizes the optional sounds.

The design and review process applied the pinned Better Interface guide by Jakub Krehel (MIT), commit `267330e1adfc66a718fb65fa6918c1f06d0a689e`: https://github.com/jakubkrehel/skills/tree/267330e1adfc66a718fb65fa6918c1f06d0a689e/skills/better-interface.

The design documentation method is adapted from Paul Bakaus's Impeccable (Apache-2.0), commit `9d715cc4f5564a990ca8345abfdd5df6dc9b41c8`: https://github.com/pbakaus/impeccable/blob/9d715cc4f5564a990ca8345abfdd5df6dc9b41c8/skill/reference/document.md. Copyright 2025 Paul Bakaus. Documentation was adapted to describe this game's implemented system; it is not an unchanged copy of the reference.

Both guide licenses are preserved in `docs/licenses/design-guidance.txt`. Vite, TypeScript, Playwright and axe are development tools; their packages and licenses are obtained by the lockfile installation and are not shipped in `dist/`.
